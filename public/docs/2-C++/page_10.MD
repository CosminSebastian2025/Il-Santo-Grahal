## Obiettivi di apprendimento

- capire cos'è un puntatore
- usare `&` e `*` in modo corretto
- conoscere i fondamenti di memoria
- distinguere stack e heap

---

### Puntatori

```cpp
#include <iostream>

int main() {
    int numero = 42;
    int* ptr = &numero;

    std::cout << "Valore: " << numero << "\n";
    std::cout << "Indirizzo: " << ptr << "\n";
    std::cout << "Valore puntato: " << *ptr << "\n";

    return 0;
}
```

### `&` e `*`

- `&numero`: indirizzo della variabile
- `*ptr`: valore puntato dal puntatore

### `nullptr`

```cpp
int* ptr = nullptr;
```

### Stack e heap

- `stack`: memoria locale e automatica
- `heap`: memoria allocata dinamicamente

### Perché è importante?

I puntatori sono importanti per capire come il programma gestisce i dati e la memoria, ma al livello iniziale serve solo averne una visione base.
