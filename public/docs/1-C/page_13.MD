## Ripasso rapido

### 1. Variabili e tipi
- dichiarare variabili
- usare `int`, `float`, `double`, `char`
- leggere e stampare dati

### 2. Librerie
- includere file esterni con `#include`
- capire il ruolo delle librerie standard

### 3. Input e output
- usare `printf` e `scanf`
- leggere valori da tastiera
- mostrare risultati a schermo

### 4. Condizioni
- `if`, `else`, `else if`
- operatori di confronto
- operatori logici

### 5. Cicli
- `for`
- `while`
- ripetere azioni in modo automatico

### 6. Funzioni
- definire funzioni
- usare parametri e ritorni
- organizzare il codice

### 7. Array
- gestire più dati insieme
- usare gli indici
- lavorare con cicli

### 8. Stringhe
- array di caratteri
- terminatore `\0`
- leggere e confrontare testi

### 9. Puntatori
- indirizzi di memoria
- passaggio per riferimento
- collegamento tra array e puntatori

### 10. Memoria dinamica
- `malloc`, `calloc`, `realloc`, `free`
- gestione delle risorse

### 11. File
- `fopen`, `fclose`, `fprintf`, `fscanf`, `fgets`
- leggere e scrivere file di testo

### 12. Progetto finale
- riunire tutti i concetti
- costruire un programma completo

## Esercizi extra avanzati

Questi esercizi sono pensati per chi vuole andare oltre il livello base.

### Extra 1: Ordinamento di numeri
Scrivi un programma che:
- chiede all'utente 10 numeri
- li salva in un array
- li ordina in ordine crescente
- li stampa

### Extra 2: Ricerca in un array
Scrivi un programma che:
- chiede un numero da cercare
- controlla se è presente nell'array
- stampa la posizione se trovato

### Extra 3: Password semplice
Scrivi un programma che:
- richiede una password all'utente
- controlla se è corretta
- mostra un messaggio di accesso consentito o negato

### Extra 4: Calcolo della media e della mediana
Scrivi un programma che:
- legge 5 valori
- calcola la media
- trova il valore centrale
- stampa i risultati

### Extra 5: Gestione di una lista dinamica
Scrivi un programma che:
- alloca elementi in memoria dinamica
- permette di inserire e visualizzare valori
- libera la memoria alla fine

### Extra 6: File con record
Scrivi un programma che salva in un file dati come:
- nome
- cognome
- età
- voto

Poi leggi e stampa i dati dal file.
